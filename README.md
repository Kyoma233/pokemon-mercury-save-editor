# 宝可梦 水银 · 离线存档修改器

GBA 宝可梦改版 **《宝可梦 水银》**（Project Azoth）的**单文件离线存档修改器**：把 `.srm` / `.sav` 拖进页面即可读取、编辑、导出，全部在浏览器本地完成，**不联网、不上传**。

## 使用

**在线版：** <https://kyoma233.github.io/pokemon-mercury-save-editor/>

也可以直接下载本仓库的 `index.html` 双击打开（功能完全相同，纯离线）。

1. 先**备份存档**。
2. 把存档拖到页面里（支持 mGBA 的 `.sav` 与常见的 `.srm`）。
3. 改完点「导出修改后的存档」，覆盖回游戏存档目录即可。

## 功能

| 模块 | 内容 |
|---|---|
| 队伍 / 电脑箱子 | 25 箱 × 30 格；编辑物种、等级、经验、个体值、努力值、**性格**、**特性（含隐藏特性）**、性别、闪光、招式、携带道具、亲密度、相遇地点与等级、来源（相遇 / 孵化 / 交换）；新建宝可梦、复制、移动、清空箱子 |
| 背包 | **全部道具**（跨口袋自动归类）+ 道具 / 重要道具 / 精灵球 / 技能机·秘传机 / 树果 / 电脑（PC 道具）六个口袋 |
| 训练家 | 姓名、ID/SID、金钱、游戏币、游戏时间 |

- 中文名表（物种 1553、道具 749、招式 1014、特性、相遇地点）**取自本改版 ROM**，并与官方资料站 [Project Azoth Wiki](https://sum-light.github.io/azoth-wiki/) 交叉核对。
- 导出保留原文件长度与头部，14 个扇区校验和自动重算；`.srm`（物理布局）与 mGBA `.sav`（逻辑布局 + 尾部 16 字节）都支持。

## 说明

- 本改版修改过存档结构（去掉加密与打乱、物种编号重排并扩展、箱子改成 58 字节自定义记录、校验按实际使用长度），所以 **PKHeX 读不了**；本工具是按实测结构实现的，细节见 [`save-format-notes.md`](save-format-notes.md)。
- 各口袋容量是**游戏本体容量**（道具 42 / 重要道具 30 / 精灵球 13 / 技能机 58 / 树果 43 / 电脑 30）。工具允许写入更多，但会在界面上明确提示「超出部分游戏内不会显示」。
- 写入前请务必备份存档；因使用本工具造成的存档问题请自行承担。
